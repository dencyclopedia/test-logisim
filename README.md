# test-logisim (temporary)

Temporary public test lab for the logisim.dev planning package. It tests the **official
Logisim-evolution release assets** on GitHub-hosted Windows, macOS and Ubuntu runners
(`.github/workflows/lab.yml`) and commits raw results to `results/`.

- `lab/circuits/` small test circuits generated by the logisim.dev lab scripts
- `results/<run>/<runner>/` raw outputs (hashes, install trees, signing/Gatekeeper checks,
  headless runs, screenshots)

This repository will be deleted when the project is complete; the results are mirrored into
the private planning repository.
